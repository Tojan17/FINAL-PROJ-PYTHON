# Aid Distribution System

A Python-based terminal application for managing and tracking humanitarian aid inventory.  
The system allows users to add, distribute, search, and generate reports for aid shipments efficiently.

---

## Features

- Display all available aid items
- Add new shipments or update existing items
- Distribute aid with quantity validation
- Search for specific items
- Generate detailed inventory reports
- Save and load data from local storage (JSON-based)

---

## Technologies Used

- Python 3
- JSON for data storage
- File handling
- Modular programming (separated functions)
